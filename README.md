# SpeakLoop · 口语复盘

一个专为「每周 1–2 次一对一英语口语课」设计的课后复习 App。
上完课后把老师讲的**词汇、短语、语法**录进来，App 用**间隔重复算法**帮你安排复习，并配了**填空、跟读、造句、AI 陪练**四种巩固拓展练习。

- 无需安装、无需注册，数据 100% 保存在你自己手机的浏览器里
- 支持安装到手机主屏幕（PWA），可离线使用
- AI 功能为可选，不配置也完全可用

---

## 快速开始（手机 + 电脑同一 WiFi）

1. 电脑上双击 **`start.bat`**（需要装有 Python 或 Node.js 任一）
2. 窗口里会打印出局域网地址，例如 `http://192.168.1.5:8899`
3. 手机浏览器打开该地址
4. iPhone：Safari → 分享 → **添加到主屏幕**；
   Android：Chrome → 菜单 → **添加到主屏幕/安装应用**

之后从主屏幕图标进入，像原生 App 一样全屏使用（电脑开机且启动了 start.bat 时可用；断网也能用）。

> 想随时随地在手机上用？把这个文件夹部署到任意静态托管（Vercel / Cloudflare Pages / GitHub Pages 均免费），用手机访问托管地址并「添加到主屏幕」即可，不再依赖电脑。

## 日常怎么用（推荐节奏）

| 时机 | 动作 |
|------|------|
| 课后 10 分钟内 | 点底部 **＋**，把新词/短语/语法录进来（标签默认就是今天，方便按课次回看）|
| 每天任意 5 分钟 | 打开 **复习**，清空「待复习」；忘记的卡片 10 分钟后会自动再出现 |
| 周末 / 碎片时间 | 进 **练习**：填空挑战 → 跟读模式 → 造句挑战，各来一轮 |
| 下次上课前 | 进 **词库**，按最新排序快速翻一遍上次课的内容 |

## 功能说明

### 🎯 复习（间隔重复）
- 每张卡片按记忆情况自动安排下次复习时间：
  - **记得** → 间隔逐渐拉长（1天 → 3天 → 7天 → … → 最长180天），间隔满 30 天标记「已掌握」
  - **想起来了** → 稍后在本轮再出现一次
  - **忘记** → 10 分钟后重新出现，且缩短后续间隔
- 默认「看中文说英文」（练口语输出），可在「我的」里改为「英→中」
- 答案面带 🔊 朗读、🐢 慢速例句，回答时**务必说出声**

### ＋ 录入
- 三种类型：📘 单词 / 💬 短语 / 🧩 语法（语法卡可写讲解、常见错误）
- **批量导入**：每行一张卡，格式 `英文 | 中文释义 | 例句(可选) | 例句翻译(可选)`，
  语法卡写成 `语法：名称 | 讲解 | 例句`
- 每日新卡上限默认 20 张（「我的」里可调），防止一次录入太多消化不了

### 💪 巩固拓展
- **填空挑战**：从例句里挖掉目标词（自动识别 committed 等变形），凭提示填回
- **跟读模式**：听一句、跟一句，支持常速/慢速，练语感和发音
- **造句挑战**：看中文释义口头造句，再对照参考例句
- **AI 口语陪练**（可选）：与 AI 用英语情景对话，它会自动纠错，并引导你使用自己词库里的词

### ✨ AI 助手（可选配置）
配置后解锁两个能力：录入时 **AI 一键补全**（释义/音标/例句/搭配/拓展词）、**AI 口语陪练**。

1. 去「我的 → AI 助手」选择服务商预设（智谱 GLM 有免费模型 `glm-4-flash`，DeepSeek、Kimi、OpenAI 也可）
2. 填入对应平台的 API Key
3. 点「测试连接」确认可用

> API Key 只保存在你手机本地浏览器中，不会上传到任何第三方。
> 若测试连接报 CORS/网络错误，说明该服务商不支持浏览器直连，换一个服务商即可（智谱 GLM 和 DeepSeek 一般可用）。

### 🙂 统计与数据
- 总卡片 / 待复习 / 连续打卡 🔥 / 已掌握，以及最近 7 天复习量图表
- **导出备份**：生成 JSON 文件（建议每周一次，换手机或清浏览器数据前必做）
- **导入备份**：选择之前导出的 JSON 即可整体恢复（覆盖当前数据）

## 常见问题

- **换手机 / 清了浏览器数据怎么办？** 用「导出备份」的 JSON 在新设备上「导入备份」即可。
- **示例卡片能删吗？** 能，词库里点开 → 删除。首次打开预置的 3 张示例只是演示。
- **电脑上双击 index.html 打开行不行？** 行，功能完整；只是没有离线缓存和「添加到主屏幕」的完整体验，推荐用 start.bat。
- **复习提醒（推送）有吗？** 当前版本没有，建议绑定固定时间（如午饭后）打开清一遍「待复习」。
- **8080/8899 端口被占用？** 编辑 start.bat，把 `set PORT=8899` 改成其他数字。
